# SITREP // DAILY

Personal daily ops brief: a PWA plus a JSON feed for a KWGT home-screen widget.

| File | What it is |
|---|---|
| `index.html` | Six-page brief: Reveille (+ board), Mission (Big 3, open actions, projects), Train (PT / dry fire), Mind (memory palace, habit, discipline, gratitude, thought record), Ledger, AAR. Copy to Obsidian. |
| `sitrep.json` | Today's feed, rewritten daily at 1645 CT by a scheduled task |
| `program.json` | 7-day garage PT and dry-fire rotation, plus `SHIFT` A–D work-day PT. Edit it to change the training plan |
| `WIDGET.md` | KWGT build steps for the S25 Ultra and Z Fold 7 |

**OPSEC:** this repo is public (required for free GitHub Pages). The feed must never contain health, legal, financial, or personal-contact detail. Appointments are shown generically. Anything typed into the app stays in the phone's local storage.
